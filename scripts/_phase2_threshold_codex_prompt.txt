LOWER section score threshold from 2 to 1

CONTEXT
The wiki retriever in v1/retrieval/wiki_retriever.py has a hard floor:
  if score >= 2:
      relevant.append((score, section))

This blocks single-meaningful-word queries (V07 query "What did you do
when the merchant came for you?" has only "merchant" as a non-stopword
match). With multi-query rephrasings adding more candidate words, the
threshold may now be over-restrictive.

The change is intentionally aggressive: with CRAG downstream filtering
on relevance, lowering recall threshold and letting CRAG prune noise
should net positive.

CHANGE (one-line edit)
File: v1/retrieval/wiki_retriever.py
Function: retrieve_sections (around line 168-188)

The score check is currently:
    if score >= 2:
        relevant.append((score, section))

Change to:
    if score >= 1:
        relevant.append((score, section))
